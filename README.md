# Wraith Client

A custom Minecraft launcher for Windows with built-in mod injection, cheat client support, and auto-update.

## Features

- **Cracked & Premium** — offline (cracked) and Microsoft account (premium) login
- **Auto Fabric/Forge** — installs the correct loader automatically for any version
- **WraithMod** — built-in HUD mod with coordinates, FPS, CPS, keystrokes, fullbright, and more
- **Cheat Clients** — toggle Meteor Client, OpSec, and LiquidBounce per version from the Cheats tab
- **Auto-Update** — prompts on launch when a new version is available, installs silently
- **Discord Rich Presence** — shows current version and playtime
- **Quick Connect** — set a server IP to join automatically on launch
- **RAM & JVM control** — Aikar's flags pre-configured, fully customizable

## Installation

Download the latest setup from [Releases](https://github.com/Armand220/WraithClient/releases/latest) and run it.

## Building from Source

**Requirements:** .NET 8 SDK, Windows

```
git clone https://github.com/Armand220/WraithClient.git
cd WraithClient
dotnet build -c Release
```
